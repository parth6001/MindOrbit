# Privacy

Your reminder data stays on this device.

Internet access is not required. No account is required. MindOrbit has no analytics, advertising, tracking, crash-upload service, Firebase, cloud storage, or cloud synchronization. The manifest does not declare INTERNET or ACCESS_NETWORK_STATE.

All financial, IPO, subscription and email information is manually entered. There are no live prices, mailbox access, bank integrations, or market announcements.

The Room database and DataStore files are inside Android's private application sandbox. Automatic Android cloud backup and device transfer are disabled. Notifications have private lock-screen visibility, although Android and the user's notification settings determine final presentation.

Export is an explicit user action through the Android Storage Access Framework. JSON and CSV exports contain plaintext data. Choose a local folder; another document-provider app can independently offer cloud destinations. MindOrbit does not upload files or include a network client. Files previously exported are not erased by Delete all data or uninstall.

Delete all data removes reminders, tags, custom categories, local history and preferences, cancels alerts, and recreates the built-in empty category catalog. It does not perform forensic storage erasure. Device encryption and a strong screen lock protect against physical access.
